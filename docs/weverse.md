# Weverse 监控

入口：管理面板 → 配置 → Weverse。沿用现有 QQ 消息格式 `【成员名|Weverse动态 / 回复 / 直播】`，附原文、可用的中文机器翻译、图片、原文链接和北京时间。

## 使用

1. 点击「打开 Weverse 登录」，在面板的浏览器页完成登录并加入 Hearts2Hearts 社区，然后回到 Weverse 配置点击「同步登录态」。不要通过聊天发送密码或 token。
2. 在 Weverse 账号设置中将翻译语言设置为中文。翻译使用网页自己的翻译接口，不额外收费接入第三方翻译服务，不自动修改账号设置。
3. 搜索 Hearts2Hearts、H2H、成员官方名（例如 CARMEN），或粘贴社区链接。搜索基于实时公开目录，缓存一小时；选择团体后，通过登录态加载成员 ID。
4. 选择整团或指定成员，填写 QQ 群号，选择发帖、回复、开播、翻译和 @全体，再添加订阅。整团会使用每次采集的成员目录，因此会包含后来加入的成员。
5. 先点「只读测试」，确认实际内容及译文。它只展示最近十条匹配内容，不发 QQ 消息，也不改推送去重状态。确认后开启总开关并保存运行设置。配置在下一轮检查生效，无需重启。

Hearts2Hearts 的公开社区 ID 是 235，官方目录当前列出 CARMEN、JIWOO、YUHA、STELLA、JUUN、A-NA、IAN、YE-ON。成员订阅保存的是登录后返回的 ID，不用名字匹配推送。

## 行为与限制

- 首次启用、重新启用、变更成员 / 事件选择或目标群，只建立基线，不补发旧消息。正常重启读取持久化去重记录；消息入队后记录事件 ID。
- 回复通过社区通知定位原帖，读取艺人评论及楼中楼回复，校验作者是否为该社区成员。相同通知新增评论时会重新检查，按实际评论 ID 去重。不会将通知标为已读。
- 读取动态、通知和评论分页。后续扫描从上次成功检查前五分钟开始覆盖；单类最多二十页，超出时报告错误，不推进成功检查时间。
- 韩文原文始终保留，中文译文紧随对应文本。翻译失败仍推送原文。图片内文字、语音和直播音频不做翻译。
- 只监控当前登录账号有权访问的网页内容。首次真实登录测试前，不能保证账号可见的每一种回复通知及直播结构都已兼容。共同直播、以团体官方账号发布的直播，以及未出现在社区通知中的回复，需使用真实样本验证；目前按内容作者的成员 ID 筛选。
- Access token 过期时使用 refresh token 自动续期，刷新与浏览器同步通过跨进程文件锁协调。账号退出、撤销会话或续期失效后，需回面板重新登录同步。
- 存储位于配置文件同目录的 `storage/weverse/`：`settings.json`、`session.json`、`state.json`、`status.json`。会话文件权限为 0600；面板接口只返回是否已配置，不返回 token。该目录不能提交到 Git。

## 实现参考与验证

协议依据 [Weverse 网页](https://weverse.io/hearts2hearts/artist) 的当前公开客户端脚本及 [yt-dlp Weverse 提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/weverse.py)；Go 客户端独立实现，无新增第三方运行服务。

自动测试：`go test ./internal/weverse ./internal/logic ./internal/admin`，以及 `node --test sidecar/weibo-auth/weverse-session.test.mjs`。

公开目录实测：`WEVERSE_LIVE_TEST=1 go test ./internal/weverse -run TestLivePublicSearch -v`。这一测试不需要登录，不代表已完成真实发帖、回复及开播测试。


回复提醒仅根据回复者身份筛选：回复者属于目标成员就转发，被回复者可以是粉丝、成员本人或其他成员。粉丝发出的回复不转发。提醒显示双方昵称，中文回复在前，原文分隔显示；接口账号标识保存在事件的 memberId / parentMemberId 字段。

直播选项同时控制开播和结束提醒。开播通知附标题、中文译文（可用时）、封面和直播链接；结束通知保留标题、封面和链接，有时长则显示时长。仅跟踪监控期间观察到的直播，列表消失后查询该直播详情，只有 LIVE/DONE 或明确 liveToVod 状态才通知结束；请求失败、404、未知状态不会当作结束。跟踪和通知去重状态持久化，重启不会重复通知。

直播结束后继续等待回放，只有转为 VOD、encodingStatus=COMPLETE 且具备视频播放标识才发送一次回放生成通知。结束与回放分别去重，等待状态保存到磁盘，重启后继续检查（保留七天）。@全体成员可单独指定成员，不影响其他成员订阅和转发；未指定时兼容原有全部成员设置。

QQ 消息顶栏统一为【成员名|Weverse】。对话显示被回复者在上、成员回复在下；中文直接用昵称标注，下方原文在昵称后注明“（原文）”，不使用单独语言标题或实线。文字后依次放图片、链接、空行和纯时间戳，不显示“时间：”或“链接：”标签。

## AI 帖子整理

实时转发继续使用 Weverse 自带翻译；AI 整理在后台单独执行。按订阅和主帖 ID 收集成员新回复，同一帖子内的成员与粉丝对话、队友互动和成员自己的评论合并整理，不同帖子不会混合。收集到的发帖成员、主帖原文、图片数量/视频标识，以及每条回复和被回复消息的原文一同发送给已配置的 AI。图片和视频只提供元数据，不分析画面。

一组内容中的实际回复成员连续五分钟没有新的监控回复后，且最近扫描正常，触发整理；同一成员仍在其他帖回复时继续等待。间隔可在面板修改；这是根据消息推断的安静时间，不是成员在线状态检测。

AI 先生成译稿，再将原文和译稿一起送入独立审校请求，纠正指代、肯定/否定和专名，并同步修订总结；只有完整结果通过程序校验才发送。Hearts2Hearts 整理附带成员名单、S2U 粉丝名和 2aN 品牌等术语背景。生成与审校共用面板设置的任务等待上限，失败沿用退避重试。

输出先显示主帖中文，再按时间保留完整中文对话，被回复者在上、成员回复在下，最后附对话总结、主帖链接和纯时间戳。程序校验每条回复 ID 必须恰好翻译一次，拒绝遗漏、重复、截断或原句未翻译的结果，并使用原始记录中的昵称标注说话者。翻译结合原帖语境补足省略句，但 AI 仍可能误译。

旧版本未完成的成员分组缓存会自动按主帖重新分组并重新翻译；已经完成的整理不会自动重发。只整理启用后监控到的新回复，不自动补扫历史。@全体仍按实际回复者的订阅规则执行，不因主帖或被回复者是 STELLA 就 @全体。

### 跨时段帖子上下文与视频

以链接中的主帖编号归档原始记录，`history.db` 保存采集事件及每个订阅已入队转发的记录。AI 每次读取同帖全部已转发历史（跨小时、重启保留），主帖与所有已转发回复按时间逐条翻译，并标明本次新增数量。不同主帖隔离；只采集成员实际发出的回复。翻译先生成再审校，对已知错误感叹词及残留韩文执行校验，失败后退避重试。已删除、无权限或从未采集的内容不保证完整。

帖子上传视频从 `orderedAttachments` 识别，并通过网页登录态取得播放信息，优先选择不超过 50 MiB 的高清文件。无法取得播放文件时保留封面和原帖链接，并提示含视频。AI 仅知道视频元数据，没有分析画面或音轨。

### 成员活动报告邮件

面板「配置 → Weverse → 成员活动月报 / 半年报 / 年报」可开启定期邮件、设置北京时间发送时刻，并选择期间预览、下载 Excel、回采可见历史或手动发送。报告沿用微博超话日报的 `ALERT_EMAIL_*` 发件人与收件人配置，发送 Excel（七张工作表）和 PNG 汇总附件。

- 月报：次月 1 日发送上个月；上半年报：7 月 1 日发送 1–6 月；年报：次年 1 月 1 日发送全年，默认 09:00。
- 首次启用不自动补发已结束的早期报告。手动可选择早期期间；尚未完整回采时会在邮件与附件显著标明范围。
- 发帖和回复分别按稳定内容 ID 去重；主帖照片按张数统计，视频按实际附件数量统计（不含直播回放）。封面不计入图片发布量。直播按发起账号计一次开播，结束和回放不重复计数，也不推测出镜成员。
- 回复总数按直接被回复者拆成粉丝、其他成员、自己和身份未知；直接回复成员矩阵记录具体目标 ID。评论/点赞汇总本期发布帖子的最新采集累计值，缺失不会当作零，活动明细记录采集时间。Moment 单独计数，只保证已采集内容，过期记录可能无法恢复。直播列出有时长数据的已知累计时长，参与者未确认时不推测单人。
- 半年报、年报在同一 PNG 中按月份排列八位成员的完整指标对照，Excel 另附逐月成员数据。
- 队友帖下回复按主帖作者与回复成员的 ID 计算；回复粉丝但发生在队友主帖下仍计入，自己的帖子下回复队友不计入。主帖作者未知时单独说明，不猜归属。
- 原始活动、主帖编号、回复关系与附件元数据保存在本地 SQLite。Excel 含成员汇总、队友帖回复矩阵、队友帖回复明细、全部活动原文、统计说明、直接回复成员矩阵、逐月成员数据，保留零活动成员。
- 定期发送前回采当期可见记录：遍历历史主帖（包括当期之前发布的帖子）及其成员评论，并读取直播历史。历史回采不更新实时游标、不补发旧动态、不把未转发的历史评论加入 AI 已转发上下文。分页超过上限、登录失效、接口失败会报错，保留已采集记录；权限不足的私密或已删除帖子单独标记并继续回采；已删除或不可见内容不保证可恢复。
- SMTP 成功后记录发送状态，失败一小时后重试。历史回采和生成邮件在后台运行，不阻塞实时通知。邮件成功与本地完成状态写入之间若进程崩溃，仍可能重发。

CLI 可生成附件或手动发送：

```sh
go run ./cmd/weverse-report -kind monthly -year 2026 -month 9 -backfill -out /tmp/weverse-report
# 添加 -send 发邮件，添加 -enable 开启三种定期报告
```

### QQ 视频通知

带视频消息先发送文字、`[视频]` 占位提示与封面，再发送一条独立视频。卡片中的链接与时间在封面之后，并以空行分隔。视频没有播放文件时，仅发送占位提示、封面和原帖链接。@全体只放在文字卡片，视频不重复 @全体。
