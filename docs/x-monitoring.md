# X 监控

配置页新增 X 分组：启用开关、检查间隔、网络代理，以及账号搜索、订阅编辑、暂停、删除和只读预览。搜索支持用户名、主页链接与昵称；保存订阅时由服务端确认账号编号，防止仅凭昵称订阅错人。

运行配置独立保存在 `storage/x/settings.json`，不修改其他平台配置或会话。每轮重新读取，保存后下次检查生效。当前首个目标为 `nekomo_st`，沿用主绑定 QQ 群，默认转发帖子/引用，不转发回复、转发帖或 @全体；这些选项可在订阅中修改。

采集使用现有 twscrape 侧卡与私密账号会话。相同账号多个群的订阅共享本轮采集结果；同一账号同一群不允许重复订阅。

首次检查建立并保存基线，不发送历史内容。此后按账号编号、帖子编号去重；延迟出现的旧记录不当成新帖。固定帖不能单独证明扫描与历史重叠；必要时扩大扫描窗口，仍无重叠则保留进度、显示异常。采集或状态保存失败时不继续推进。状态在文件中持久化，重启不依赖短期日志判断健康。

QQ 文本、图片及视频封面位于同一消息，视频保留占位提示并单独发送。链接位于媒体下方，链接与北京时间之间留空行。优先选择不超过约 2.5 Mbps 的视频版本，减少发送过大文件；沿用 Bot 的本地/远程媒体配置。推送状态表示进入现有 OneBot 队列，不代表额外实现了 QQ 送达确认。

总览显示 X 开关状态、最近扫描、账号数量、新内容入队数量及错误；过久没有完成扫描会显示异常，最近活动保留 X 的实际扫描结果。

Weverse 和 X 采用其他平台的配置行、蓝色开关、输入框及按钮样式。Weverse 侧栏数量为运行设置 3 项、AI 设置 6 项、报告设置 5 项，共 14 项；X 运行设置 3 项。数量不包含临时预览条件与订阅记录条数。

验证包含 Go 去重/身份/固定帖/媒体发送/服务状态/会话隐私测试，Python 媒体与验证码过滤测试，前端编译，以及真实面板搜索、只读预览、编辑、保存、桌面和手机布局检查。Browser plugin not available；界面验证使用已安装的 Playwright。实际 X 首轮成功采集 100 条帖子，仅建立基线。
