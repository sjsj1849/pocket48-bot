## 密码帖子

已从官方网页发布 `weverse3/3_17_5` 的 `Cg4T-d1P.js` 确认 `getPost` 和 `getPostForPasswordCheck` 都以帖子 ID 调用 `/post/v1.0/post-{postId}`，密码通过 `lockPassword` 查询参数提交。官网错误常量包含 `INVALID_POST_PASSWORD: post_700`，与会员资格、短信验证、地域限制等访问错误分开。因此不能把任意 403 都认定为缺密码。

匹配方案明确：面板输入官方帖子链接 → 解析社区与帖子 ID → 输入密码 → 使用当前登录态验证 → 成功后按 `communityId/postId` 保存，后续取原帖/翻译/上下文复用。页面只显示“已配置”，密码保存在私有存储、不放链接通知或日志。对已经跳过的原帖应提供定向重采及是否补发的明确控制，沿用持久去重，避免修改密码引起重复转发。

本轮已完成接口与设计验证，尚未添加密码面板，也没有已知真实密码帖进行成功解锁测试。可以利用成员提示、粉丝明确贴出的密码和引用的原帖链接提供带来源的候选线索；缺少原帖引用时关联不可靠，不应自动把 AI 猜出的密码用于循环尝试。

## 私密帖密码配置（2026-09-15 后续实现）

Weverse 现有配置页增加“私密帖密码”，支持帖子或评论链接；从 URL 提取唯一 Post ID，候选密码通过官方 postV1 / lockPassword 查询验证后，原子保存到 `storage/weverse/post-passwords.json`（0600）。面板仅返回帖子链接、ID 和验证时间，不返回密码；可删除。

正文、通知上下文、线程采集和报表补采共用 post detail 请求，签名前按精确 Post ID 注入密码；配置了密码的 artistTabPosts 会重新读取完整正文。候选覆盖旧密码仅发生在验证成功后；post_700 区分为“密码不正确”，其他权限错误保留原分类。未重置推送游标，不重发历史消息。已有帖可使用原报表补采来更新，AI 后续读取同帖上下文自动使用密码。

测试已验证特殊字符编码、保存/复用/删除、错误候选保留旧密码、文件权限、API 脱敏和不可信链接拒绝。尚无真实私密帖及已知密码样本，因此真实解锁仍待样本验证。
