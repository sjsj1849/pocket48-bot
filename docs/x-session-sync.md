# X 浏览器会话同步

X 浏览器使用已有的持久化 Chromium 配置目录。采集用的两项会话 Cookie 保存于 `storage/x/session.json`（目录 0700、文件 0600，Git 忽略）。

- 浏览器启动且没有完整 X 会话时，从私密文件恢复有效的 `auth_token`、`ct0`。
- 本机私有命令 `x_panel_import` 可以显式把文件中的会话导入浏览器；响应只返回导入状态。
- 每 60 秒检查浏览器 Cookie；X/Twitter 页面收到响应后，等待 1.5 秒再同步。
- 仅当两项 Cookie 完整、未过期且发生变化时，原子更新采集文件。退出时也同步一次。
- 浏览器缺少会话时保留原文件；自动同步不发登录请求、不导航页面，也不会抢占用户当前标签页。

这是 Cookie 同步，不是保证续期的机制。只有网站实际更新 Cookie 时，更新才会被保存。服务器撤销会话、身份验证或风控仍可能要求重新登录。

验证：Node 测试覆盖启动恢复、定时同步变化、私密权限、不完整会话保护、显式覆盖；真实侧卡导入和读取验证两项 Cookie 与采集文件一致，面板 VNC 检查不包含 Cookie 值。
